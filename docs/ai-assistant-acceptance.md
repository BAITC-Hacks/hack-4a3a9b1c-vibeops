# Проверка AI-помощника — 23.09.2026

Ветка реализации: `codex/ai-concierge`, база — `b54d3fa`. Старые незакоммиченные правки общего извлечения цитат (`evidence.ts`, `index.ts`, `provider.ts` и их новые тесты) не включены в отдельную проверяемую копию AI-помощника.

## Чистая копия

Из Git-базы и только файлов AI-помощника создана временная копия без `.env`, `node_modules` и `dist`. Выполнены `npm ci --offline` из локального кэша зафиксированных зависимостей, `npm run build`, `npm test`, `npm run test:ui`. Результат: сборка прошла, **87 серверных тестов и 44 UI-теста прошли**. Это проверка на ноутбуке Арлана; запуск на втором компьютере ещё не проверен. Новых зависимостей нет.

Новые проверки покрывают извлечение/уточнение/исправление условий, отсутствующую дату и бюджет, неизвестную категорию, невозможные даты, несколько обязательных языков, лимиты пожеланий и сообщений, Unicode JSON, непроверяемые цитаты, ID, ошибки и таймауты API. UI проверяет явное подтверждение условий, сохранение пожеланий при ручной правке и игнорирование устаревших ответов.

## Настоящий OpenAI

С локальной серверной конфигурацией `gpt-4.1-mini` выполнен `node --import tsx tests/explanations/assistant-live.ts --live`, результат — `AI_ASSISTANT_LIVE_PASS`.

- Неполный запрос о ведущем на корпоратив в Алматы оставляет дату/бюджет пустыми и требует уточнения.
- Уточнение «10 октября 2026, 500 тысяч тенге, русский, 5 часов» превращается в соответствующий Query без подстановок из формы.
- Для пожеланий «интерактивы» и «живая музыка» у единственного подходящего профиля нет основания: оба остаются в `to_confirm`.
- При бюджете 1 млн и пожеланиях про юмор, танцы и отсутствие долгих речей возвращаются три профиля в порядке `HK-88430 → HK-27222 → HK-29829`. AI выбирает разные точные цитаты; отсутствие основания остаётся видимым.
- Исправление даты на 11 октября 2026 и бюджета на 700 тысяч меняет эти поля, сохраняя остальные условия.

Отдельные вызовы сравнения заняли около 1,35 и 2,66 секунды. Это единичные замеры, не SLA. Смысловое соответствие цитаты пожеланию — интерпретация модели; сервер проверяет источник цитаты, а не объективную истинность сведений подрядчика.

## Браузер и локальный запуск

Production-сборка запущена на `http://localhost:3000`. В браузере проверены ввод запроса, распознанные поля, явное подтверждение, три карточки и персональные цитаты/вопросы в карточках. Существующий интерфейс разработки на `http://localhost:5173` использует тот же обновлённый backend.

## Ограничения

- NVIDIA не интегрирована. Нужны серверные OpenAI API key и model; отсутствие доступа не маскируется успешным AI-ответом.
- Один поиск поддерживает один город, дату, формат, категорию и язык. До пяти дополнительных пожеланий сравниваются по описаниям, не становятся гарантиями или скрытыми фильтрами.
- Дату нужно указывать с годом; сокращённое исправление даты может вызвать повторное уточнение года. Относительные даты пока требуют точной календарной даты.
- Доступ жюри, проверка на втором ноутбуке и сдача на платформе этим изменением не закрываются.
