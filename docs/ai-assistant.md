# AI-помощник: интеграционный контракт

По поручению Арлана 23.09.2026 AI становится основным пользовательским входом в подбор. Это изменение прежнего приоритета P2 для свободного текста. Обязательные условия и стабильный порядок существующего поиска сохраняются.

Для этой реализации распределение работ: основной агент — shared/assistant.ts, server/app.ts, интеграционные проверки и README; агент brief — новые server/explanations/assistant-brief.ts и его тесты; агент comparison — новые server/explanations/assistant-compare.ts и его тесты; агент interface — client и новые tests/ui/Assistant.test.tsx. Имеющиеся незакоммиченные правки explanations/evidence.ts, index.ts, provider.ts и distinct-evidence.test.ts сохраняются.

- POST /api/assistant/brief: `{messages: string[]}` (последовательность реплик пользователя, максимум 8, до 2000 символов каждая и 8000 суммарно). Сервер вызывает модель, валидирует результат и отдаёт AssistantBrief из shared/assistant.ts. Пропущенные обязательные поля не заполняются значениями формы по умолчанию. `query: null` означает необходимость уточнения. Новая реплика может корректировать прежние условия.
- Пользователь видит извлечённые условия, пожелания и вопросы. Нажатие «Подобрать по этим условиям» запускает существующий POST /api/recommend с проверенным query. Пожелания сверх параметров поиска показываются отдельно и не выдаются за гарантии.
- POST /api/assistant/compare: `{query, preferences}`. Сервер сам получает первые три профиля существующим selectVendors; модель связывает пожелания с фрагментами описаний. Сервер проверяет ID, пожелания и непрерывные цитаты. Для каждого пожелания без допустимой цитаты показывается необходимость уточнения. Смысловую связь определяет модель, это не независимая проверка профиля. Данные о ценах и занятости определяет существующий поиск.
- Ошибки используют ApiError: неверный ввод 422, отсутствие конфигурации/сбой AI 503, таймаут 504, неверный результат модели 502. Ошибка AI не маскируется успешным AI-ответом.
- Только существующие серверные OPENAI_API_KEY и OPENAI_MODEL. SDK Responses API с text.format/json_schema, store:false, maxRetries:0. Секреты не попадают в ответы, логи и клиент.
