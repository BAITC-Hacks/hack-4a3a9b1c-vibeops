# Проверка релиза Firebird

Проверено 23.09.2026, до дедлайна 18:00 Asia/Almaty. Кандидат релиза: `v0.1.0`. Проверяемая production-реализация — коммит `3de000c7bbaaba655d8ffc8b5453db51ac1acfca`. Последующая интеграция истории ветки Никиты `1c081b6` не изменила runtime-файлы; добавлены регрессионный тест и этот отчёт. При публикации проверить отсутствие runtime-diff между этим коммитом и тегом. Итоговый SHA хранится в GitHub Release и теге, а не подменяется SHA старого отчёта.

Проверки выполнены на Node.js 24 в изолированной рабочей копии и отдельном чистом клоне из официального GitHub-репозитория. Это не проверка на втором физическом компьютере. Ни `.env`, ни ключи в репозиторий и результаты не включены.

500 USD → приблизительно **223 925 ₸** по справочному курсу НБК на23.09.2026 (447,85 ₸/USD). Источник, дата курса, исходная сумма и необходимость подтверждения показаны пользователю. «100 гостей» не превращается в бюджет; исправление USD на300000₸ заменяет старую сумму. Сетка fallback: все сочетания городов, категорий и форматов, 100 дат, бюджет6000000₸, без языка/часов. Среди **7624 непустых выдач**: совпавших полных объяснений — **0**, повторяющихся цитат внутри выдачи — **0**, чужих/несуществующих цитат — **0**. В451 выдаче честно раскрыто отсутствие отдельного отличия в исходных данных. Профили `HK-25279` и `HK-92824` по-прежнему могут остаться без содержательной цитаты из-за скудного описания.

Ранее сообщённые453 выдачи с одинаковым текстом относятся к прежнему коммиту5289994. Новая сетка подтверждает устранение этого типа повторов в указанных условиях, но не доказывает идеальную смысловую оценку всех запросов. Полная цитата и соответствие ID проверяются программно; смысловую связь пожелания с описанием оценивает модель, она может ошибаться.

## Известные ограничения и незакрытые проверки

- В промежуточном production-прогоне по одному разу получены502 `AI_INVALID_RESPONSE` в brief-коррекции бюджета и сравнении подарков. Непроверяемый ответ отклонён, а не показан как факт. Для brief добавлены строгие варианты цитат из сообщений; финальная сетка14/14 прошла. Подарочное сравнение затем прошло через HTTP и3 холодных SDK-вызова. Исходные неудачные ответы не сохранены, поэтому первоначальная причина не установлена и случайный отказ модели не объявляется невозможным.
- Длинные предложения сравнения, которые нельзя безопасно сократить до220 символов, не используются; полезное пожелание может остаться в «Нужно уточнить». Это консервативное ограничение, а не доказательство отсутствия услуги.
- Ранее в dev-браузере с реальным CSV пройдены D1–D6, альтернативы и экраны320/390px. **Заключительный production UI с живым API браузером не проверен:** CUA недоступен, у установленного Playwright отсутствует исполняемый браузер. HTTP и компонентные тесты не заменяют этот прогон; он передан Нурболу.
- Запуск на компьютере другого участника, способ доступа жюри к AI и подтверждение сдачи на платформе остаются отдельными пунктами команды. GitHub Release сам их не подтверждает.
- Ранжирование лексическое и детерминированное. Обучения/дообучения модели, NVIDIA-интеграции, бронирования и итоговой сметы нет. Цена «от» и календарь — данные каталога, не обещание поставщика.
